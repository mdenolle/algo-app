# Algo invents the set

Algo does not copy instruction books. It designs a LEGO model piece by piece from
the real catalogue, then tells you which pieces you need. Open `/builder/` to see
one in 3D, walk the steps, and print the piece list.

## How it works

| File | What it does |
|---|---|
| `parts.generated.js` | The shapes Algo may use, from `catalog/catalog.json`: real part numbers, official names, stud footprints and heights in plates (a brick is 3 plates). Generated by `catalog/designer-parts.mjs` (`npm run designer:parts`); wheels, axles and pins are left out because they do not sit on a stud grid. |
| `colors.generated.js` | The official LEGO colours, with their real names and RGB. |
| `inventory.js` | What you own: how many of each part in each colour. `openPile()` is Algo designing freely (then it tells you what to find); `demoInventory()` is a mixed tub, used to check a design can be built from a limited box. |
| `model.js` | The build itself: pieces on a stud grid (x, z in studs, y in plates). Every placement is checked — you must own the piece, the space must be free, and it must rest on something. The finished model is checked again for being one connected thing with nothing floating. |
| `designs.js` | Eight shapes Algo knows how to invent: house, car, rocket, dog, tower, plane, bridge, robot. Each reads the pile, picks sizes and colours that fit, and lays bricks with `line`, `slab` and `box`. A seed makes a build repeatable; a new seed gives a different one. |
| `instructions.js` | Numbered steps ("Put 5 red 2 × 2 bricks…"), the parts list, and the picture of each real piece (Rebrickable element photo, falling back to a rendered part image). |

## Rules the designer follows

- **Only real pieces.** Every part number and colour comes from the verified catalog, and LEGO really made that part in that colour (there is an element id for it).
- **It has to hold together.** Side-by-side bricks do not count as joined: something must span them. Walls take turns owning the corners, and a floor or roof ties them.
- **Nothing floats.** Every piece rests on the baseplate or on a piece below.
- **You can follow it.** The steps are in build order: a piece is never asked for before what holds it up.
- **It fits your box.** Given a real inventory, the design never uses a piece you do not have.

`npm test` checks all of this for every design across several seeds.

## Adding a design

Add a function to `designs.js` that takes `(inventory, seed)` and returns a
`Model`, then list it in `DESIGNS`. Build with `line` (a row of bricks), `slab`
(a floor or roof that ties things together), `box` (four walls) and
`model.placeAny([...])` for a single piece. The tests will tell you if it floats,
falls apart, or asks for pieces nobody has.
